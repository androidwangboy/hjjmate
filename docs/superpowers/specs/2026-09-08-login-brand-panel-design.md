# 登录页左侧品牌区设计（方案 A）

- 日期：2026-09-08
- 范围：`mateclaw-ui/src/views/Login.vue`（模板 + scoped 样式）及登录 i18n 文案
- 决策：采用可视化对比中的方案 A（沉稳左对齐 + 描边胶囊 Tag 网格）

## 背景

登录页当前结构为"背景图 + 右侧登录卡片"，左侧大面积背景图没有品牌信息。
需求是在左侧增加平台主标题、副标题口号和六个协同 Tag，强化医疗行业品牌心智。

## 布局

- 在 `.login-page` 内、`login-center` 之前新增 `.login-brand` 区块。
- 桌面端：`.login-page` 改为左右分布（`justify-content: space-between`），品牌区居左垂直居中，
  登录卡片保持右侧，最大宽度 420px 不变。
- 品牌区右移：`margin-left: clamp(24px, 4vw, 80px)`、
  `margin-right: clamp(24px, 3vw, 72px)`，紧贴登录卡片左侧、
  保持安全间距，让出左侧星云图形区域。
- 平板 / 移动端（`max-width: 900px`）：隐藏品牌区，登录卡片居中（复用现有移动端逻辑）。

## 视觉规范

- 主标题：`AI` + `数智协同` / `智能体平台` 分两行；
  800 加粗、无衬线栈
  `'Source Han Sans SC','MiSans','PingFang SC','Microsoft YaHei',sans-serif`；
  `clamp(38px, 3.6vw, 46px)`；`letter-spacing: 3px`。
  汉字为冰青竖向渐变（白 → `#d9faf3` → `#9fd8e8`）+ 双层辉光；
  `AI` 独立斜体金属银渐变、辉光更强；`AI` 为语言无关的品牌符号，直接写在模板中。
- 科技横线：标题下方通栏 1px 光束线（青 → 透明）+ 椭圆核心光斑，还原参考图的横线 flare。
- 副标题：`为医护减负增效，为家庭加护增康`；
  淡青色 `rgba(178, 235, 220, 0.7)`；15px；`letter-spacing: 6px`。
- 分割线：副标题下方 64px 渐变细线，过渡到 Tag 区。
- 协同 Tag（医护协同、护患协同、护管协同、护康协同、业考协同、质控协同）：
  3 列网格、描边胶囊（`1px solid rgba(0, 255, 200, 0.25)`，
  背景 `rgba(0, 255, 200, 0.06)`，文字 `rgba(210, 245, 235, 0.9)`），13px。
- 品牌区只用静态样式，不加动画；`prefers-reduced-motion` 下无影响。

## 文案与国际化

- 文案走 `login.brand.*` i18n key（含英文翻译，英文副标题使用正常字母间距），不硬编码。
- 六个 Tag 文案同样走 i18n，便于后续英文版替换。

## 非目标

- 不改右侧登录卡片结构、表单逻辑、SSO 流程；
- 不改背景图与移动端卡片样式；
- 本次不引入新字体文件，仅使用系统已装字体栈回退。

## 验证

- CSS/模板类变更，无自动化测试覆盖；以人工视觉验收为准。
- 验收：桌面端 `http://localhost:5173/login` 左侧品牌区按规范渲染；
  窄屏（≤900px）品牌区隐藏、卡片居中；中英文切换文案正常。
